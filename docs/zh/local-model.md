# 本地模型

Agora 可导入 GGUF 模型，通过 llama.cpp 在设备端推理；也可以使用 [Cactus](https://github.com/cactus-compute/cactus) 引擎运行以预构建 `.cactus` 包发布的模型。

## 导入与使用

打开**设置 → 提供商 → 本地**导入 GGUF 文件。Agora 会把模型复制到应用管理目录，并可在支持时关联多模态投影文件。导入的模型会自动启用，可从**设置 → 模型**或聊天模型选择器使用。

## Cactus 引擎

Cactus 是独立的设备端推理引擎，拥有自己的内核和 CQ（旋转式 1–4 位）量化权重——它不使用 GGUF 文件。在**设置 → 提供商 → 本地 → 添加 Cactus 模型**中，可以直接从官方模型仓库下载现成的包（例如 CQ4 的 Gemma 4 E2B，或超小的工具调用模型 Needle），下载带校验和与进度显示；在电脑上自行转换（`cactus convert`）的包则可通过 `.zip` 压缩包或文件夹导入。

Cactus 模型在本地模型列表中带有专属徽标，聊天体验与 llama.cpp 模型完全一致：流式输出、思考过程、工具调用、图片（多模态包）与消息统计均同样可用。Cactus 自行管理上下文窗口并始终运行自己的 CPU 内核，因此 Auto/CPU/Vulkan 运行时切换仅对 GGUF 模型生效。

完整的 Cactus 内核要求 64 位（arm64-v8a）版本的 Agora。在 32 位手机上，Agora 改为内置 Cactus 官方预编译的 Needle 3 引擎：目录提供单文件 needle3.cact 模型（约 35 MB），可校验和下载或从 .cact 文件导入。Needle 3 是工具调用专精模型——它会根据会话已启用的工具挑对工具并填好每个参数，全程在设备上完成。它不进行自由聊天：未启用工具时会回复一条说明，工具回合则把模型推理作为思考过程展示。完整 Cactus 模型（Gemma 4 E2B）仍需 64 位版本，所有 llama.cpp 模型照常运行。

同一目录还提供 **Whistle**，Cactus 的设备端语音识别模型：一个 16.9 MB 的 .cact 单文件，与 Needle 3 运行在同一个引擎上，驻留在当前聊天模型旁边。安装后聊天输入框会多出一个麦克风按钮（在发送旁）：按住录音，松开插入转写文本，左滑取消——即 WhatsApp 的交互方式。口述适用于所有本地聊天模型（.cact 或 GGUF），自动识别语言（英语、德语、法语、西班牙语、意大利语、荷兰语、波兰语），每段最多 30 秒，全程不出设备；首次按住时会请求麦克风权限。Whistle 会驻留在聊天模型旁，应用冷启动后的第一次口述会先加载模型（约 17 MB）再转写。从目录行移除 Whistle 后，麦克风按钮随之消失。

模型所需内存、上下文能力和速度取决于 GGUF 与设备。大模型或大上下文可能很慢，或在内存不足时失败。

## 删除

删除已导入模型会移除 Agora 管理的 GGUF 和关联投影文件，不会删除应用目录之外的无关源文件。Whistle 语音模型不是聊天模型：在**添加 Cactus 模型**的目录行中移除。本地 llama.cpp 推理不依赖 Alpine 沙盒；后者是单独的 F-Droid 功能。
